# Quiet Preview for Netflix

Netflixのホーム画面上部で再生されるおすすめ作品（ビルボード）と、作品詳細を開いたときのプレビューだけを、ミュートまたは指定音量にするChrome拡張です。「再生」ボタンから開く視聴プレイヤー（`/watch/...`）には設定を適用しません。ミュートを維持するか、Netflix標準の音声ボタンで解除できるようにするかを選べます。

対象プレビューのNetflix標準音声ボタン付近には、拡張機能が制御中であることを示す「🔇 ミュート」または「🔉 20%」のバッジを表示します。音量指定時のスピーカーアイコンは、0%で「🔇」、1〜49%で「🔉」、50%以上で「🔊」になります。マウスを重ねたときに開く小さな作品カードでは、Netflixのボタン再描画による位置ずれを防ぐため動画右下の一定位置に表示します。Netflixのボタン自体は変更しないため、表示の位置検出に失敗しても音量制御には影響しません。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダーを選ぶ

Netflixをすでに開いている場合は、拡張機能の読み込み後にNetflixのタブを再読み込みしてください。

## 使い方

Chromeのツールバーにある拡張機能のアイコンを開き、次のいずれかを選びます。

- 「常にミュート」: Netflix標準の音声ボタンを押してもミュートを維持する（初期設定）
- 「開始時はミュート」: プレビュー開始時はミュートし、Netflix標準の音声ボタンで解除できる
- 「音量を指定」: プレビューだけを0〜100%の指定音量にする
- 「プレビュー上にミュート・音量を表示」: 状態表示だけをON/OFFにする（音量制御には影響しません）
- 「音量調整」をオフ: 拡張機能が変更前の音量設定を復元する

## 対象範囲

`billboard` を識別子に含むNetflixのおすすめ領域と、`previewModal` または `?jbv=...` で識別される作品詳細ダイアログ内の動画だけが対象です。通常の作品一覧、本編プレイヤー、および `/watch/...` の動画は対象外です。Netflix側の画面構造が変更された場合は、`content.js` の `AUTOPLAY_CONTAINER_SELECTORS` を更新してください。
